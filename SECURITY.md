# Security Policy

## Supported versions

Security fixes are provided for the latest released minor version.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue for a suspected vulnerability.

Do not include real receipt images, names, addresses, phone numbers, payment information, membership identifiers, or purchase histories in a report. Create the smallest synthetic reproduction possible.

We aim to acknowledge reports within seven days. Acknowledgement is not a promise of a particular fix or release date.

## Security and privacy boundary

This package itself performs no network requests and stores no data. Applications integrating it control storage, logs, analytics, backups, and transmission. Parsed fields are untrusted input and must be reviewed and validated before consequential use.
