# Code of Conduct

## Our pledge

We pledge to make participation in this project respectful and harassment-free for everyone.

## Expected behavior

- Be respectful and constructive.
- Discuss technical tradeoffs, not personal characteristics.
- Protect privacy: never post real receipts or personal purchase data.
- Accept maintainer decisions about project scope.

## Unacceptable behavior

Harassment, discriminatory language, threats, publishing private information, and sustained disruption are not tolerated.

## Enforcement

Report conduct concerns privately through the maintainer contact options on the GitHub profile. Maintainers may edit or remove contributions and temporarily or permanently restrict participation when necessary.
